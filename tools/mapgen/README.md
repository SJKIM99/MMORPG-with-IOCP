# tools/mapgen — 마을 원본 → 공유 헤더

마을(지금은 데니차)의 칸 · 층 · 건물 · 이름 있는 자리를 **사람이 고치는 텍스트 층**으로 두고, 생성기가 검사한 뒤
서버 · 클라가 함께 쓰는 `GameServer/Data/TownMap.h`(생성물 — 직접 고치지 않는다)와 미리보기 그림을 만든다.

```
python3 tools/mapgen/gen_town.py            # 기본: tools/mapgen/denica
```

고친 뒤에는 생성기를 돌리고 서버 · 클라를 다시 빌드한다. 생성기는 규칙을 어기면 칸 좌표와 함께 멈춘다.

## 파일(`tools/mapgen/denica/`)

| 파일 | 내용 |
|---|---|
| `town.txt` | 이름 · Zone · 원점(월드 칸) · 크기(너비 높이) |
| `ground.txt` | 칸마다 바닥 · 막힘 문자 한 글자(행 = y). 글자 뜻은 아래 |
| `height.txt` | 칸마다 층 `0`~`4`(들판 = 0). 계단 칸은 낮은 쪽 층 |
| `buildings.txt` | `종류 x0 y0 x1 y1 [door=S] [variant=n] [sign=간판]` — 마을 기준 칸, 양끝 포함. 발자국 칸은 `B` |
| `anchors.txt` | 이름 있는 자리 — `spawn`(부활 · 귀환 · 첫 접속) · `dummy`(허수아비) · `yard`(훈련장 사각형) · 그 밖의 이름(`south_gate_out` → `TownMap::kSouthGateOut`) |
| `districts.txt` | `이름 \| 설명 \| x y \| 줌` — 투어(`--script tour`) · 지도 이름 |
| `ambient.txt` | `종류 x y 반경` — 소리 구역(분수 · 시장 · 대장간 · 종 · 강 · 바람) |

## 바닥 문자

| 걷는다 | 막힌다 |
|---|---|
| `.` 풀밭 · `=` 포석 길 · `,` 광장 판석 · `:` 흙길 · `s` 모래 · `G` 성문 · `b` 다리 · `g` 묘지 풀 · `^ v < >` 계단(그 방향으로 한 층 오른다) | `#` 성벽 · `O` 망루 · `B` 건물 · `F` 분수 · `T` 나무 · `L` 가로등 · `*` 꽃밭 · `S` 가판대 · `R` 가장자리 · `~` 물 · `X` 바위 · `h` 산울타리 · `c` 밭 · `P` 막히는 소품 · `W` 낮은 담 |

## 높이 규칙 — 서버 충돌 격자(불리언)로 절벽을 표현한다

- 상하좌우로 맞닿은 걷는 두 칸은 **층이 같거나 계단이 잇는다**.
- 낮은 걷는 칸과 맞닿은 높은 걷는 칸은 생성기가 **가장자리 `R`(막힘)** 로 바꾼다 — 층이 다른 걷는 칸 사이에는 늘 막힌 칸이 있다.
  그래서 서버 이동(한 옆이라도 열려야 대각)과 강제 이동(`MoveRule::DiagOk`)이 절벽을 넘지 못한다.
- 계단의 오르는 쪽은 한 층 위, 내려오는 쪽은 같은 층의 걷는 칸. 계단 옆 칸은 막혔거나 같은 방향 · 같은 층 계단(넓은 계단).
- 건물 발자국은 한 층 위에 있다.
