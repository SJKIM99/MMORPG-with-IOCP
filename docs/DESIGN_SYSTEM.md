# 하르벤 — 디자인 시스템 「새김」

> 화면에 나오는 모든 것(창 · 버튼 · 글자 · 숫자 · 표식 · 일러스트)은 이 문서의 토큰과 부품으로만 만든다.
> 게임 속 그림(캐릭터 · 몬스터 · 배경 · 소품 · 아이콘 · 효과 · 창 무늬 · 커서)과 대사 음성은 [9장](#9-게임-그림--higgsfield)의 규칙으로 만든다.
> 이름과 말투는 [WORLD.md](WORLD.md). 코드는 `Client2D/src/ui/Ui.h`(`ui::theme` · `ui::type` · 부품), `ui/Font.h`(글꼴 계열).

---

## 0. 원칙

1. **세계에서 나온 모양.** 올란의 새김 글자 → 모서리를 깎은 판(새김판)과 가는 선. 데니차(샛별) → 지평선 위의 작은 마름모(◆). 이 두 가지가 이 게임의 모든 장식이다.
2. **강조색은 하나 — 새벽빛.** 바탕은 새벽이 오기 전의 먹빛 청회색, 글자는 종이빛. 새벽빛(호박색)은 초점 · 주 버튼 · 핵심 값 · 메인 이야기에만. 옛길 · 마법 · 이동은 청록.
3. **읽히는 것이 먼저.** 수치는 숫자 글꼴, 이름은 굵게, 설명은 흐리게. 한 화면에서 가장 중요한 것 하나만 밝다.
4. **쓰지 않는 것:** 금테 두 줄, 광택 그라데이션 띠, 둥근 알약 버튼, 보라 · 네온 글로우, 번쩍이는 테두리 애니메이션, 과한 그림자, 장식용 별 · 반짝이 남발, 흰 말풍선.

## 2. 타이포그래피 (`ui::Face` · `ui::type`)

| 계열 | 글꼴 | 쓰임 |
|---|---|---|
| `Body` | Pretendard Medium | 본문 · UI 기본(장시간 읽어도 피로하지 않은 현대 산세리프) |
| `Strong` | Pretendard SemiBold | 이름 · 버튼 · 소제목 · 목록의 제목줄 |
| `Bold` | Pretendard Bold | 강조 · 퀘스트 ! ? 표식 |
| `Display` | 고운바탕 Bold | **창 제목 · 장 제목 · 보스 이름 · 전설 아이템 이름 · 로고** — 주요 연출에만 |
| `Serif` | 고운바탕 Regular | 이야기 · NPC 대사 · 장소 문구 · 인용 |
| `Number` | Barlow Condensed SemiBold | HUD 수치 · 좌표 · 가격 · 진행도(숫자는 고정폭) |
| `NumberBold` | Barlow Condensed ExtraBold | 피해 숫자 · 연속 타격 수 |
| `Latin` | Marcellus | 영문 로고(HARVEN) · 영문 연출(LEVEL UP) |
| `Symbol` | 나눔스퀘어라운드 Bold | ◆ ◈ ★ ♪ 같은 기호 폴백(직접 쓰지 않는다) |

- 모두 SIL OFL 1.1 글꼴이다(`Client2D/assets/fonts/OFL-*.txt`). 고운바탕은 KS X 1001 한글 2,350자 + 게임에 쓰는 글자로 줄였고(예약 이름 없음), 없는 글자는 자동으로 Pretendard가 대신한다.
- 크기는 "줄 상자 높이"다. 계열이 달라도 같은 크기면 한글 높이 · 세로 중심이 맞도록 `Font.cpp`의 계열별 배율 · 기준선이 보정한다 — 한 줄에 여러 계열을 섞어도 된다(예: "공격 **18**").

**크기 단계** (`ui::type`, 1280×720 기준 px)

| 토큰 | 크기 | 계열 | 예 |
|---|---|---|---|
| `kDisplayXL` | 52 | Display | 로고 |
| `kDisplayL` | 36 | Display | 장 제목 · 엔딩 |
| `kDisplayM` | 26 | Display | 새 장소 · 보스 등장 |
| `kDisplayS` | 20 | Display | 카드 제목 · 퀘스트 이름 |
| `kTitle` | 17 | Display | 창 제목 |
| `kHeading` | 15 | Strong | 이름 · 소제목 |
| `kBody` | 14 | Body | 본문 |
| `kBodyS` | 13 | Body | 목록 · 툴팁 본문 |
| `kCaption` | 12 | Body | 보조 설명 · 라벨 |
| `kMicro` | 11 | Strong | 단축키 · 배지 |

- **행간** 150%(`kLeading` = 크기 × 0.5를 줄 사이에 더한다). 이야기(Serif)는 155%.
- **자간**: 본문 0. 제목(Display)은 +0.5~1px, 장 제목 · 로고는 +4~16px로 넓게. 라벨(Strong 12)은 +0.4px.
- **숫자**: 값은 언제나 `Number` 계열. 라벨은 `Body`로 흐리게, 값은 `Number`로 밝게.
- **느낌표**: 시스템 메시지 · 알림에는 쓰지 않는다. 위험 경고("벗어나세요!")에만.

## 3. 모양 · 간격

- **새김판** `ui::Plate(r, fill, border, chamfer, borderW)`: 모서리를 45°로 깎은 판. 깎는 크기 — 창 5 · 툴팁 4 · 버튼 · 칩 · 목록 줄 3 · 칸 · 단축키 2.
- **선** `ui::Rule`: 1px, 정수 픽셀. 구분선은 `kLine`, 창 테두리는 `kLineStrong`.
- **간격**: 4px 격자(4 · 8 · 12 · 16 · 24). 창 안쪽 여백 12~18. 창 제목줄 37px(제목 + 가는 선 + 새벽빛 짧은 획 22px).
- **그림자**: 판 아래로 2~6px, 검정 40% 한 겹. 글자 그림자는 1px(24px 이상 2px).
- **움직임**: 창 · 알림은 0.12~0.35초 이징(EaseOutCubic/Back). 테두리 맥동은 "지금 해야 할 일"(보고할 퀘스트 · 선택된 목적지)에만.

## 4. 부품

| 부품 | 규칙 |
|---|---|
| 창 `ui::Window` | Panel + 제목(Display 17, 왼쪽 정렬) + 가는 선 + 새벽빛 짧은 획. 닫기는 선으로 그린 ×. |
| 판 `ui::Panel` | kSurface0 + kLineStrong 테두리 + 위쪽 1px 빛. `fancy`면 3px 안쪽에 옅은 두 번째 선(새김 홈). HUD 판은 `fancy = false`. |
| 버튼 `ui::Button` | Normal(표면2) · Primary(짙은 새벽빛 바탕 + 새벽빛 테두리 · 글자) · Danger(짙은 불씨) · Ghost. 글자는 Strong. 광택 대신 위쪽 1px 빛. |
| 칸 `ui::SlotFrame` | kSlot + kLine. 호버 = 흐린 테두리, 선택 = 새벽빛 2px. 희귀도 = 바닥 2px 띠. 착용 = 오른쪽 위 새벽빛 삼각형. |
| 툴팁 | 희귀도 색 1px 테두리 + 위쪽 2px 띠. 이름: Strong 16.5(전설 이상은 Display 18) → 부제(희귀도 · 부위) 12.5 → 가는 선 → 성능(Strong) → 옵션(◇ · ◈) → 특수 효과(◆) → 세트 → 착용 조건 → 비교(▲▼). |
| 막대 `ui::Bar` | 평면 색 + 위 1px 밝게 · 아래 1px 어둡게 + 현재 값 눈금. 줄어든 몫은 종이빛으로 잠깐 남았다가 따라온다. 글자는 Number. |
| 단축키 `ui::Keycap` | 작은 새김판 + Strong 11. 켜짐 = 새벽빛. |
| 소제목 `ui::SectionHeader` | Strong 12.5 흐리게 + 오른쪽으로 이어지는 가는 선. |
| 목록 줄 | 표면1 → 호버 표면2 → 선택 표면3 + 왼쪽 2px 새벽빛 막대. |
| 알림 띠 | 가운데만 짙은 먹빛, 아래 1px 선(알림 색), 글자는 Display 19. |
| 토스트(주운 물건) | 작은 새김판 + 왼쪽 2px 색 막대 + 아이콘 + Strong 14. |
| 말풍선 | 먹빛 반투명 새김판 + 종이빛 글자(Body 13.5). NPC와 플레이어가 같은 모양. |
| 이름표 | Strong 14.5 + 1.4px 외곽선. NPC 역할은 그 위 Body 11.5 흐리게. 보스는 Display 18 + 양옆 불씨색 마름모. |
| 퀘스트 표식 | ! 새 이야기 · ? 보고 (Bold, 새벽빛). 말 걸 대상은 먹빛 말풍선 + 새벽빛 점. |
| 지역 위험도 | 샛별(◆) 다섯 개 — 채운 개수가 단계(1~3 새벽빛, 4 주황, 5 불씨). |
| 로고 `ui::Logo` | "하르벤"(Display, 넓은 자간) → 지평선과 샛별 → HARVEN(Latin) → 부제(Serif, 새벽빛). |
| 창 관리(`ui/Wm`, Phase 3-A) | 모든 창: 제목줄로 끌기(3px 움직여야 시작 — 클릭이 창을 흔들지 않게) · 누른 창 · 새로 연 창이 맨 위 · Esc는 맨 위 창부터 · 화면 가장자리와 다른 창 · HUD 덩어리 변에 **8px 자석** · 해상도가 바뀌어도 화면 안. 크기를 바꾸는 창(채팅)은 가장자리 · 모서리 6px 띠, 커서가 ↔ ↕ ↘↖ ↗↙로 바뀐다. **열기 0.14초**(96% → 100% · 투명 → 불투명, 끝이 부드럽게) · **닫기 0.12초**(97%로 줄며 사라짐). 겹친 창 뒤의 단추는 눌리지 않는다(마우스 아래 맨 위 창만 입력을 받는다). |

## 8. 새 화면 체크리스트

1. 색은 `ui::theme` 토큰만. 새 색이 필요하면 이 문서에 먼저 올린다. 알파만 다르면 `util::A8(토큰, 알파)`.
2. 글자는 역할에 맞는 계열 · 크기 토큰으로. 숫자는 `Number`.
3. 판 · 버튼 · 칸 · 선은 부품 함수로(`Plate` · `Panel` · `Window` · `Button` · `SlotFrame` · `Rule`). `DrawRectangleRounded`를 직접 쓰지 않는다.
4. 강조는 한 화면에 하나. 새벽빛은 "지금 볼 것"에만.
5. 이름 · 문구는 WORLD.md 규칙으로.
6. 넣은 뒤 `python3 tools/consistency/check.py` — 이름(용어집) · 쓰지 않는 말 · 보라 · 네온 · 토큰 흉내 · 말투를 한 번에 본다. FAIL이 0이어야 한다
   (예외는 `tools/consistency/allow.txt`에 이유와 함께 — 이유 없는 예외는 읽지 않는다).

## 9. 게임 그림 — Higgsfield

게임 속에서 보이는 그림은 모두 Higgsfield(GPT Image 2.5)로 그렸다 — 플레이어 3직업 · 몬스터 34종 · NPC 13명 · 동물 3종 · 바닥 20장 · 벽 · 지붕 6장 · 소품 40개 · 아이콘 99개 · 효과 40개 · 창 무늬 · 커서.
주문서는 `tools/assetgen/catalog.py`, 가공은 `process.py`, 결과는 `Client2D/assets/`(만드는 법은 [tools/assetgen/README.md](../tools/assetgen/README.md)).
**그림 파일이 빠져도 게임은 돌아간다** — 모든 자리에 예전 절차적 그림이 대신 선다.

### 9.1 스타일 문구 — 한 게임처럼 보이게

모든 주문은 종류마다 정해진 스타일 문구로 끝난다(`STYLE_*`). 바꾸려면 catalog.py의 문구만 고치고 다시 뽑는다.

| 종류 | 문구의 뼈대 |
|---|---|
| 캐릭터 · 몬스터 · NPC · 동물 (`STYLE_SPRITE`) | 손그림 느낌의 2.5D 아이소 다크 판타지 · 또렷한 실루엣 · 옅은 먹선 · **왼쪽 위 따뜻한 빛 + 옅은 청록 테두리빛** · 청회 · 청록 · 호박 · 흙빛 · 사실적인 비례(치비 금지) · 투명 배경 · 그림자 · 글자 · 격자선 없음 |
| 소품 (`STYLE_PROP`) | 같은 빛 · 같은 팔레트 · 바닥면 · 그림자 없음 |
| 바닥 · 벽 · 지붕 (`STYLE_TEX`) | 이음매 없는 반복 · 위에서 곧게(벽은 정면에서) · 방향 그림자 없음 · **초점 없이 고르게** · 중간 이하 대비 · 손보다 큰 물체 없음 |
| 아이콘 (`STYLE_ICON`) | 칸 가운데 80% · 왼쪽 위 빛 · 테두리 · 숫자 · 글자 없음 |
| 효과 (`STYLE_FX`) | **순검정 바탕**에 빛나는 것만(더하기 혼합으로 검정이 사라진다). 연기 · 먼지만 투명 바탕 |
| 건물 (`STYLE_BUILDING` + `BUILDING_BLUEPRINT`, Phase 4-C) | 소품과 같은 빛 · 팔레트 + **키트 건물 그림을 설계도 참고 그림으로** — 구도(2:1 쿼터뷰 · 남동에서) · 발자국 · 화면 속 자리 · 크기 · 실루엣을 그대로 두고 재질만 다시 그린다. 투명 바탕 · 사람 · 글자 · 보라 · 네온 없음 |

- 빛의 방향(왼쪽 위)은 게임의 그림자 · 초상화 · 일러스트와 같다. 보라 · 네온 · 광택은 쓰지 않는다(0장 4).
- 사람은 **대화창 초상화를 참고 그림**으로, 플레이어 동작판은 **직업 기본 그림을 참고 그림**으로 뽑는다(얼굴 · 옷 · 무기가 흔들리지 않게). 옷 · 무기 설명(`PLAYER_KEEP`)을 매 주문에 되풀이한다.

### 9.2 동작판 — 2x2 격자 한 장 = 자세 넷

- 1024px 한 장에 **같은 대상 네 자세**. 아이소 3/4(약 35°), **오른쪽 아래를 본다**(왼쪽을 볼 때는 뒤집는다). 발은 칸 아래 같은 기준선, 칸끼리 닿지 않는 넉넉한 여백.
- 뒷모습 판(플레이어가 위쪽으로 움직일 때)은 오른쪽 위를 보고 **얼굴이 보이지 않게** — "FROM BEHIND"를 주문에 박는다.

| 대상 | 판 | 자세 |
|---|---|---|
| 플레이어(직업마다) | 기본 + `act` · `cmb` · `back` | 서기 · 걸음 두 장 · 준비(젖힘) · 휘두름 · 기술 · 막기(회피) · 맞음 · 쓰러짐 · 뒷모습(서기 · 걸음 둘 · 공격) |
| 몬스터 | 1장 | 서기 · 움직임 · 공격(오른쪽 아래로 끝까지 뻗음) · 맞음 — 움직임 · 공격 말은 원형(archetype)마다 정해 둔다(`MOVE`) |
| NPC | 1장 | 서기 · 걸음 두 장 · 말하기(손짓) |
| 동물 | 1장 | 쉬기 · 걸음 두 장 · 버릇(꼬리 흔들기 · 기지개 · 모이 쪼기) |

- **가공**: 칸마다 잘라 잡티 제거 → **몸 중심 맞춤**(알파를 깎아 낸 몸통의 무게중심 — 서기 자세의 "몸 중심 ↔ 발" 거리를 다른 자세에도 그대로 쓴다. 발끝 · 앞발에 맞추면 공격할 때 몸이 뒤로 튄다) → 아틀라스(여백 6px, 가장자리 색을 밖으로 번져 밉맵 테두리를 막는다) → `sprites/actors.txt`.
- **그리기**: 발 깊이에 세운 6줄 띠(기울기 · 눌림 · 늘어남 · 회전을 줄마다 준다). 불투명 패스는 알파 0.35 미만을 버려 깊이를 쓰고, 반투명 패스(0.02)가 부드러운 가장자리를 덮는다. 잔상 · 빛 겹은 버리지 않는다(`cutout = false`).
- **크기**: 플레이어 1.16 · 몬스터 1.14 · NPC 1.10 × 예전 절차적 키(`actors::*Height`) — 이름표 · 체력바 자리가 그대로 맞는다.

### 9.2a 동작 영상 — 한 주기 프레임(Phase 1-D)

걸음처럼 되풀이되는 동작은 **영상으로 뽑아 한 주기를 프레임으로 자른다**(`tools/assetgen/motion.py`, 기록은 `docs/upgrade/ASSETS.md`).

- **시작 · 끝 그림 = 기준 동작 한 장**(달리기는 첫 걸음 `walk1`) — 얼굴 · 옷 · 무기가 동작판과 같고, 영상이 제자리에서 이어 돈다.
- 주문 뼈대: 2D 게임 스프라이트 · **제자리에서** 이어지는 동작 · 가운데에서 움직이지 않음(이동 · 회전 · 크기 변화 없음) · **고정 카메라** · 아이소 3/4(입력 그림과 같은 각도) · **캐릭터에 없는 단색 바탕**(자홍 `#FF00FF`, 붉은 옷이면 초록) · 바닥 · 그림자 · 배경 · 빛 변화 · 줌 없음.
- 가공 규칙: 한 주기 전체가 **같은 바닥점**(카메라 고정 → 뛰어오른 프레임은 뜬 채로), 기준 동작과 **같은 배율 · 기준높이**(새 프레임과 동작판이 섞여도 몸 크기가 튀지 않는다), 장수는 주기를 고르게 나누는 수(8~16).
- 달리기 · 걷기는 **러닝머신처럼 디딘 발이 뒤로 쓸리는 영상만** 쓴다 — 발 쓸림이 게임 보폭(1.9칸/주기)의 ±20% 안. 제자리 걸음 영상은 디딘 발이 미끄러진다.
- 쓰는 곳: 앞모습 달리기(`pc_<직업>_run00…`). 걸음 위상(이동 거리 ÷ 보폭)으로 프레임을 고른다 — 0번 = `walk1` 자세 = 첫 발 디딤. 그림이 없는 방향 · 직업은 걸음 두 장 + 절차적 흔들기.

### 9.3 절차적 연기 — 그림 사이를 잇는 손맛

그림은 몇 장뿐이다. 손맛은 그 사이의 **움직임**이 만든다(`render/ActorSprites.cpp`).

| 동작 | 규칙 |
|---|---|
| 휘두름 | 준비 0~30%(뒤로 6° 젖힘 · 웅크림) → 휘두름 30~70%(앞으로 튀어 나감 · 9% 늘어남 · **준비 그림 잔상 한 장**) → 되돌아옴(한 번 튀어 오름) |
| 맞음 | 뒤로 밀리며 젖힘 + 흰 번쩍임(셰이더 팔레트) · 넉백. **히트스톱(0.06배속) 동안 그림도 거의 멈춘다** |
| 걷기 | 두 걸음 그림을 발 위상에 맞춰 바꾸고, 발이 교차할 때 몸이 올라가며 가는 쪽으로 쏠린다. 달리기 한 주기 프레임(9.2a)이 있으면 그것으로 — 오르내림은 프레임에 들어 있어 흔들기는 0.6px만 |
| 숨 · 기술 | 서 있을 때 숨(눌림 · 늘어남). 힘 모으기는 떨림, 회전 베기는 가로 배율을 1 → −1 → 1로(그림 한 장으로 한 바퀴) |
| 쓰러짐 | 맞음 그림으로 뒤로 넘어가다가(회전) 누운 그림으로 — 바닥에 쿵 닿으며 한 번 튀었다 가라앉는다 |
| NPC | 말할 때(대화 · 혼잣말) 말하기 그림과 서기를 말 박자로 오간다 |

### 9.4 효과 — 타격감

- 효과 그림은 입자(`Shape::Tex`)로 뿌린다. **튀어 나옴**(EaseOutBack으로 커졌다 가라앉음) → 사라짐. 빛은 더하기 혼합, 연기 · 먼지는 보통 혼합.
- 한 번 때릴 때 겹: 별 모양 충격(치명타는 큰 충격 + 충격파 고리) · 베기 초승달(휘두른 쪽으로 뒤집는다) · 짐승류 몬스터는 발톱 자국 세 줄. **히트스톱 동안 효과도 멈춘다**(맞는 순간이 한 장면으로 남는다).
- 바닥에 눕는 효과(고리 · 마법진 · 불 고리)는 깊이 −0.965에 납작하게(0.5). 그림 자체가 이미 비스듬한 것(불 고리 · 충격파 · 후광)은 납작하게 하지 않는다.
- 기술마다 그림 한두 장을 절차적 효과 위에 얹는다(`fx/SkillFx.cpp`) — 청록은 옛길 · 마법, 새벽빛(금)은 치유 · 레벨 업 · 강화 성공, 어두운 그림자 연기는 강화 실패.

### 9.5 배경

- **바닥**: 지역 15 + 마을 5장을 한 아틀라스(5x4, 칸 576px = 512 + 가장자리 감쌈 32px)로. 셰이더가 두 크기 · 두 각도로 읽어 노이즈로 섞고, 넓은 명암 얼룩을 한 겹 더 얹어 반복이 보이지 않게 한다. 용암 맥동 · 요정 반짝임 · 눈 반짝임은 그 위에.
- **벽 · 지붕**: 건물 종류마다 벽 · 지붕 텍스처를 정한다(잡화점 = 회칠 + 붉은 지붕, 무기점 = 돌 + 슬레이트, 신전 = 돌 + 푸른 슬레이트 …). 텍스처 한 번 반복 = 1.4칸. 성벽 · 탑은 성벽 돌.
- **건물(Phase 4-C)**: 두 겹. ① **키트**(`render/Buildings.cpp`) — 종류 19 · 주택 변형 10을 조각(벽 · 지붕 모양 · 창 · 문 · 발코니 · 차양 · 굴뚝 · 간판 · 깃발 · 탑 · 바퀴 · 날개)으로 짓고, 재질 · 색 · 밤 창빛은 **구획 규칙**(LEVEL_DENICA 3장)이 정한다.
  ② **그린 건물**(`assets/buildings`) — 랜드마크 · 큰 가게 7채는 키트 그림을 설계도로 다시 그린 그림을 올린다(`tools/assetgen/buildings.py`: 단색 바탕 촬영 → 생성 → 실루엣 겹침(IoU)으로 배율 · 자리 맞춤).
  깊이는 두 벽면의 **천막꼴**(앞 모서리가 가장 가깝다) — 상자꼴 건물에서 뒤는 가려지고 앞은 그 위에. 움직이는 것(연기 · 불꽃 · 등불 · 밤 창빛)은 키트 자리에 덧그린다. 그림이 없으면 키트.
  **땅에 붙이기**(자기 검토): 모든 건물은 빛(왼쪽 위)의 반대쪽 — 동쪽으로 높이의 30%(0.6~2.1칸) 그늘을 드리우고 남쪽 벽 밑에 접지 띠를 깐다. 키트 벽은 아래 0.45z에 때, 위 0.35z에 처마 그늘을 한 겹씩.
- **마을의 작은 생명**(`render/Critters`, 자기 검토): 비둘기 떼 5무리(분수 광장 · 남문 광장 · 시장 거리 · 결사 회관 단 · 여관 골목) — 몸 10px 안팎의 회청 · 흰 · 갈색 얼룩 · 짙은 네 빛,
  목에 청록 무지갯빛, 왼쪽 위 등빛. 쪼기 · 고개 까딱 걸음 · 천천히 걷는 주민에게는 비켜 걷기, **달려오는 플레이어 · 몬스터 · 짐승에게는 가까운 새부터 0.07초 간격으로 푸드덕**(깃털 2~4장 · 날개 소리) → 선회 → 내려앉기 직전 날개 제동 → 통 튀며 선다.
  나는 새는 바로 아래에 그림자(높을수록 옅고 작게). 밤에는 둥지로 날아가 사라지고 아침에 날아 들어온다. 개울 물고기는 포물선으로 튀어 올라 물 고리 두 겹 · 물방울 · 퐁당 — 밤에 더 자주.
- **소품**: 지역마다 쓰는 나무 · 바위 · 풀 이름과 키를 정해 둔다(`render/Props.cpp`). 마을 가로등 · 노점 · 분수는 그림 + 빛.
- **이음매**: 텍스처는 가장자리 대비를 재서(이음매 비율) 반복 주기로 잘라 내고, 좁은 띠만 섞는다(넓게 섞으면 돌벽이 두 겹으로 비친다).

### 9.6 UI 그림

- 창 바탕: 청회색 돌 결 텍스처를 1.4배로 깔아 30%만 얹는다(글자가 먼저 읽힌다).
- 큰 창(가로 120 · 세로 90 이상의 `fancy` 판)의 네 모서리에 청동 모서리 장식(38px, 5px 바깥으로) — 한 장을 뒤집어 네 모서리에 쓴다.
- 커서 넷: 화살표 · 공격(칼) · 줍기(손) · 말 걸기(두루마리). 강화 커서만 코드로 그린다.

### 9.7 목소리 · 소리

- **대사 35줄**(NPC 인사 16 · 직업마다 궁극기 · 레벨 업 · 쓰러짐 9 · 보스 5마리 등장 · 쓰러짐 10)은 Higgsfield 음성 합성(ElevenLabs)으로 만든다(`tools/assetgen/voices.py`).
  - 배역은 미리 듣기 음성의 기본 음높이(F0)를 재서 고른다 — 낮을수록 대장장이 · 보스. 아이는 반음 올리고, 사제는 큰 방 울림, 보스는 깊은 울림 + 낮은 겹, 악마는 거친 울림.
  - 말투는 WORLD.md(변경말 하오체 · 하게체, 아이는 반말). 한 번에 한 줄만(우선순위: 보스 3 > 궁극기 · 레벨 업 · 쓰러짐 2 > 대화 1 — 낮은 줄은 높은 줄을 끊지 못한다), ogg 모노 22kHz.
- **효과음 · 음악은 Higgsfield로 만들지 않는다** — Higgsfield의 효과음 · 음악 모델은 게임 제작 기능 안에서만 쓰도록 막혀 있다. 타격음 · 휘두름 · 처치음은 `audio/Sfx.cpp`가 합성한다(강타 = 딸깍 + 쓸림 + 47Hz 저음 + 부서짐 + 금속 배음 세 겹).

## 10. 전투 연출 (Phase 2)

「새김」의 절제 원칙(0장 4 — 강조는 한 화면에 하나)은 **UI**에 적용된다. 전투 연출은 이 장의 **등급표**가 기준이다 —
화려하되 예산 안에서, 그리고 **적의 예고 장판이 늘 먼저 읽히게**(예고는 보통 혼합 · 빛 버퍼에 넣지 않는다 → 블룸에 묻히지 않는다).

### 10.1 등급표 — 모든 기술은 등급 하나(`fx/FxGrade.h`)

| 등급 | 예 | 히트스톱 | 흔들림(trauma) | 화면 효과 | 순간 조명 | 입자(대략) | 바닥 자국 | 소리 겹 |
|---|---|---|---|---|---|---|---|---|
| T1 기본 공격 | 검격 1 · 2타 | 35~45ms | 0.06~0.08 | — | 1칸(32px) · 0.1초 | 10~25 | — | 2 |
| T2 일반 기술 | 방패 강타 | 55~70ms | 0.15~0.25 | 약한 블룸 | 2칸 · 0.2초 | 40~120 | 2초 | 3 |
| T3 강기술 · 차지 완성 · 연계 | 대지 가르기 3단, 증발 폭발 | 85~110ms | 0.35~0.5 | 충격파 왜곡 · 줌 펀치 3% | 4칸 · 0.35초 | 150~400 | 5초 | 4 |
| T4 각성기 | 단죄 · 낙성 · 그믐 베기 | 160~200ms | 0.7~0.9 | 암전 · 컷인 · 방사형 흐림 · 색수차 | 8칸 · 0.6초 | 600~1,500 | 9초 | 5 + 대사 |

- 치명 · 연계 · 처치는 같은 등급 안에서 위쪽까지 올린다. 연계는 한 등급 올려 T3 연출을 쓴다.
- **많이 맞힐수록 보상**: 한 번에 5마리 이상 → 흔들림 ×1.2(등급 최대치 × 1.2 상한) · 소리 한 겹 더.
- 내 기술 100%, 다른 플레이어 기술은 설정(기본 50%) — 입자 수 · 투명도 · 순간 조명 · 왜곡 세기가 함께 준다. 암전 · 컷인 · 방사형 흐림 · 색수차 · 색 빠짐은 **내 기술에만**.
- 광과민 보호: 화면 번쩍임 · 흔들림 · 색수차 · 방사형 흐림 · 암전 · 색 빠짐 절반.
- **화면 번쩍임은 스크린 혼합**(`fx::Effects::DrawScreen` — 결과 = 빛 + 바탕 × (1 − 빛), Phase 3 자기 검토): 어두운 바닥에서는 더하기와 같고, 밝은 바닥(눈밭 · 모래 · 흰 돌)은 하얗게 타지 않는다.
  더하기 혼합이던 때 설원 보스 처치(0.6 · 0.35초)는 월드 전체가 흰 판이 됐다 — 지금 보스 처치는 0.5 · 0.35초.

### 10.2 한 타격 = 5겹 이상(`impact::Strike`)

① 중심 섬광(셰이더 `Flare`) ② 충격 고리(바닥 `GroundRing`, T3부터 화면 충격파) ③ 튀는 불꽃 · 파편(입자 — T3부터 죽을 때 작은 불꽃)
④ 연기 · 먼지 ⑤ 순간 조명 — 여기에 T2부터 바닥 자국(원소별: 그을음 · 서리 · 먹물 번짐), T3부터 줌 펀치.
폭발(`Explosion`) · 내려찍기(`Slam`) · 산산조각(`Shatter`) · 먹물 폭발(`InkBurst`) · 낙뢰(`LightningStrike`) · 빛기둥(`Pillar`)은 이 겹을 원소에 맞게 묶은 조립품이다.

### 10.3 기술은 4박자

**예고**(선딜 80~250ms — 힘이 모이는 빛 · 자세 · 허공 글자) → **발동**(궤적 리본 · 투사체 · 이동) → **타격**(히트스톱은 여기) → **여운**(잔불 · 연기 · 바닥 자국 · 식어 가는 빛).
여운이 없는 기술은 싸 보인다. 느린 시간은 연출용 가짜다 — 서버 타격 시각은 바꾸지 않고 색 빠짐 · 잔상 · 음 낮추기로 느려 **보이게** 한다.
히트스톱 동안 도착한 서버 피해 숫자는 줄 세웠다가 풀릴 때 보여 준다.

### 10.6 기술 창(K) · 갈래 · 시연(Phase 2-D, `game/GameSkillGrow.cpp` · `GameSkillStage.cpp`)

- **왼쪽 목록**(12줄): 아이콘(끌어서 QWERASDF에 놓는다 · 기본 공격은 고정) · 이름(기술 색과 종이빛 반반, Strong) · 놓인 칸 `ui::Keycap` · 오른쪽 끝에 레벨(NumberBold) + 갈래 점 둘
  (고른 첫째 = 새벽빛 · 둘째 = 옛길 청록, 열렸지만 안 고름 = 빈 원). 잠긴 기술은 "Lv.n"(불씨색). 레벨이 막 오른 줄은 아이콘 테가 0.6초 반짝인다.
  **마우스를 올린 줄**을 오른쪽이 잠시 보여 준다(누르면 고정).
- **오른쪽 판**: 머리(아이콘 54 · 이름 Display · 유형 한 줄) → 기술 레벨(Number 30) · − · + · 다음 레벨 비용(모자라면 불씨색) · 피해 +n% →
  수치 한 줄(갈래를 입힌 값 — 재사용 대기 · 사거리 · 한 타 피해, 정보색) → 설명 · 연계 → 갈래 Ⅰ · Ⅱ(카드 두 장씩).
  - 갈래 카드: 표면0 → 호버 표면2 → 고름 = 갈래 색 16% 섞은 표면2 + 갈래 색 2px 테 + 오른쪽 위 작은 마름모. 잠긴 층은 제목 · 글자를 흐리게("기술 레벨 n에 열린다").
- **시연**(판 오른쪽 위, 너비의 46% · 220~300px, 432×232 비율): 월드 밖 무대에서 **실제 연출 시스템**(skillfx · vfx · trail · 입자)을 그대로 돌려 렌더 텍스처에 그린다.
  시전자는 내 모습(장비 그대로) · 허수아비 셋. 시각표는 서버와 같은 표(갈래를 입힌 복사본) — 콤보는 끝까지, 차지는 완벽 구간, 홀딩은 60%, 체인은 끝 단까지, 토글은 켰다 끔.
  한 바퀴가 끝나면 1.6초(각성기 2.4초) 쉬고 다시. 아래 2px 새벽빛 막대 = 바퀴 진행. 왼쪽 위 글자 "시연" / 갈래 카드에 마우스를 올리면 **"미리 보기 · 갈래 이름"**(고르기 전에 본다).
  무대는 화면 효과(암전 · 번쩍임 · 흔들림 · 충격파 · 아지랑이)와 소리가 없고(`fxscale::StageScope`), 창이 닫히면 아무것도 돌리지 않는다.
- **갈래 연출 규칙**: 갈래는 기술 연출 위에 한 겹을 더한다 — 넓은 범위 = 넓어진 테와 빛 점 · 끌어당김 = 가장자리에서 빨려 드는 먼지 · 속성 = 그 상태 색의 파열 ·
  묵직함 = 주 타격에 땅울림 · 재빠름 = 몸 둘레 흐름선 · 굳건함 = 방벽 껍질 · 메아리(두 번 ○○) = 원래 연출을 62% 세기로 한 번 더 + 파문 · 세 줄기 = 돌린 방향으로 같은 연출 ·
  장판(○○ 자국 · 남은 불길) = 바닥이 남아 서버 틱(0.5초)마다 테가 울린다. **원소가 바뀌는 갈래는 덧칠이 아니라 색 자체를 바꾼다** — 화염 고리 「푸른 불꽃」은
  불고리 · 불꽃 · 불씨 · 그을음 · 빛이 모두 푸르다(주황으로 칠해진 그림 조각은 쓰지 않고 색 램프 셰이더만).

  가는 선 → 기술별 몫(작은 아이콘 · 이름 · 4px 막대(기술 색과 새벽빛 섞음) · %) 여섯 줄까지. 세 허수아비를 합쳐 한 번의 측정이고, 5초 쉬면 판이 55%로 흐려지며
  "다음 타격부터 새로 잽니다". 30초 뒤 사라진다. 머리 위에 숫자판을 띄우지 않는다(이름 · 피해 숫자와 겹친다).

### 10.8 읽히는 싸움 — 글자 한 층 · 흰빛은 테두리에만 · 밝은 바닥(Phase 6 자기 검토)

로스트아크 · 던전앤파이터 전투 화면과 견주어 가장 먼저 눈에 띈 차이는 **싸움 한가운데가 안 읽힌다**였다(`docs/upgrade/PHASE_6.md` 자기 검토).
화면 가운데(내 캐릭터 · 적 · 바닥 예고)는 싸움에게 준다 — 글자는 가장자리와 위로, 흰빛은 짧게.

- **머리 위 글자는 한 층**: 대상으로 잡은 **보스**는 이름 · 체력을 화면 위 대상 판(여러 줄 체력바 · 무력화)에만 — 머리 위에 겹쳐 그리지 않는다.
  보통 몬스터는 맞으면 체력바만, 이름은 가리키거나 · 대상이거나 · Alt일 때. **내 이름표**는 싸우는 동안(내가 때리거나 맞은 지 5초 안) 감춘다(대화 중에도).
  **내 연계 이름**은 오른쪽 연속 타격 판(이름 · 소리 · 번쩍임)에서만 알리고, 적 머리 위에는 남의 연계만 작게.
- **가운데 알림은 싸움 자리 밖**: 화면 높이 16%와 대상 판 아래(보스는 판 78px, 보통 56px + 24px) 중 낮은 쪽. 예전 자리(화면 높이 27%)는 큰 적의 머리 위였다.
- **큰 부피는 흰빛으로 칠하지 않는다**: 몸 둘레 막 · 종 · 기둥 몸통처럼 넓은 면은 제 색(금빛 `#F2C47C` · 청록 `#7FD0C4` …) + 알파 60% 이하, 또는 보통 혼합의 옅은 껍데기(종: 먹금빛 16%).
  크림 · 흰빛(`#FFE8B0` · `#FFF0C8` · `#FFFFFF`)은 **테두리 · 획 · 작은 중심 섬광**에만. 넓은 흰 면은 어느 바닥에서나 그 안의 캐릭터 · 적을 지운다.
- **밝은 바닥 섞기**(`gfx::SetBrightGround(k)`): 8비트 화면에서 밝은 바닥(눈밭 바닥색 밝기 약 0.87 — 여유 0.1~0.15)에 빛을 **더하면** 곧장 흰색으로 탄다.
  그래서 k > 0이면 월드 셰이더 · 셰이더 효과(`fx/Vfx`)가 더하기 연출을 **미리 곱한 알파 + 바닥 덮기 k**로 그린다: 결과 = 색 × a + 바닥 × (1 − a·k) —
  k = 0이면 지금까지와 같은 더하기, k가 클수록 빛이 제 색(금빛 · 청록)으로 바닥을 덮는다. 빛 버퍼(블룸)에는 그대로 더하고, 합성할 때 번짐 × (1 − k × 바닥 밝기), 순간 조명은 곱하는 몫 × (1 − 0.6k).
  k는 게임이 매 프레임 정한다 — 바이옴 바닥색(팔레트 a · b)의 밝기 0.55~0.85를 0~0.75로(부드러운 계단), 밤에는 × (1 − 0.85 × 밤), 마을은 0, 지역을 넘으면 0.5초쯤에 걸쳐 바뀐다.
  지금 값: 눈밭 0.75 · 바닷가 약 0.67 · 사막 약 0.49 · 풀밭 · 숲 · 협곡 · 화산 · 마을 0. 무기 궤적 리본(`fx/Trail` — 기본 셰이더)은 그대로 더하기.
- 확인: 모로즈 보스전 같은 70초(`--script boss3`, 1280×720)에서 보스 둘레 300×300에 거의 흰 픽셀(밝기 235 이상)이 25%를 넘는 프레임 —
  Phase 5 끝 14.9%(가장 긴 흰 구간 2.5초) → 종 껍데기 뒤 11.3%(1.5초) → 밝은 바닥 섞기 · 막 색 뒤 **2.4%(0.5초)** — `tools/record/whiteout.py`.

## 12. 전체 플레이 영상 · 장면 자막 (Phase 6)
