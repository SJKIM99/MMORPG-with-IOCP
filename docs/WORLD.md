# 하르벤 — 세계관 · 작명 설정서

> 모든 이름 · 대사 · 설명의 기준 문서다. 새 콘텐츠를 넣을 때는 **이 문서의 언어 규칙으로 이름을 먼저 만들고 → 용어집(7장)에 등록한 뒤 → 데이터에 넣는다.**
> 화면 디자인(색 · 글꼴 · 창 · 아이콘)은 [DESIGN_SYSTEM.md](DESIGN_SYSTEM.md)가 같은 브랜드로 이어 받는다.

---

## 1. 한 줄

변경 북쪽 숲 한가운데에는 새벽마다 한 번 뛰는 거목, **하르벤**이 있다.
어느 밤 버려진 대성당의 종이 세 번 울렸고, 심장나무는 멈췄다. 그날부터 새벽이 날마다 조금씩 늦게 온다.

- 게임 제목: **하르벤** (HARVEN)
- 지금 이야기: **멈춘 심장**
- 정서: 어두운 동화. 무섭지만 잔인하지 않고, 쓸쓸하지만 따뜻하다. 과장 대신 절제.

## 2. 역사 (변경력 = 데니차가 세워진 해부터 센다)

| 때 | 일 |
|---|---|
| 아주 먼 옛날 | 숲지기 민족 **올란**이 하르벤을 심고 지켰다. 올란은 허공과 돌에 새기는 글자(**각인**)와, 나무뿌리를 따라 땅속으로 흐르는 길(**옛길**)을 남겼다. |
| 올란의 끝 | 남동쪽 땅이 처음 갈라졌다(**칼둔 균열**). 올란은 새벽의 씨앗 **사엔**을 하르벤 가슴에 심어 균열을 닫고, 그 뒤로 역사에서 사라졌다 — 전승일 뿐 증거는 사원 기둥의 각인뿐이다. |
| 변경력 1년 | 북쪽으로 올라온 개척민이 하르벤이 부르는 새벽을 따라 샛별 아래 마을을 세웠다. **데니차**(변경말로 '샛별'). |
| 60년 | 남쪽 **몬테라 왕국**의 **종의 교회**가 변경에 들어와 동쪽 언덕에 대성당 도시 **캄파나**(남부어로 '종')를 세웠다. 교회는 하르벤의 박동에 맞춰 새벽 종을 쳤다 — "심장이 뛰면 종이 운다." |
| 90년 | 교회와 변경민이 함께 **서약 기사단**을 세웠다. 서약은 한 줄이다. *심장을 지키고, 새벽을 지킨다.* |
| 118년 | 칼둔 균열이 다시 열렸다. 기사단장 **세베린**이 올란의 옛 사원 **올하르**에서 균열을 막았다. 기사단은 거의 전멸했고 세베린은 돌아오지 않았다. 기사들이 묻힌 곳이 **서약의 언덕**이다. |
| 190년 | 캄파나에 '잿빛 병'이 돌았다(칼둔의 기운이라는 말이 있다). 도시는 버려졌고 교회는 남쪽으로 물러났다. 필경사 **마테오** 같은 몇 사람만 데니차에 남았다. |
| 220년 (지금) | 어느 밤, 사람 없는 캄파나 종탑에서 종이 저 혼자 세 번 울렸다 — 교회에서 세 번의 종은 장례의 종이다. 그 밤 하르벤이 멈췄다. 새벽이 날마다 늦고, 짐승이 거칠어지고, **그락족**이 들녘까지 내려온다. |

**이야기가 밝혀내는 진실.** 세베린은 죽지 않았다. 균열 아래의 **그라목**에게 굴복해 서약을 깨뜨렸고(**파약**), 망령이 된 종지기들을 부려 종을 울려 하르벤을 재웠다. 그리고 옹이 속의 사엔을 꺼내 올하르 사원으로 가져갔다. 사엔에 깃든 불씨는 칼둔으로 흘러가 그라목이 삼켰다.
주인공은 새로 서약을 받은 자(서약기사 · 각인술사 · 밤사냥꾼)로서 그 흔적을 거꾸로 밟아 간다.

## 3. 민족 · 세력과 언어

이름은 **그 대상을 처음 부른 사람들의 언어**로 짓는다. 언어마다 소리 규칙이 달라서, 이름만 들어도 어느 쪽 것인지 구분된다.

### 3.1 올란어 — 사라진 숲지기 (성지 · 유물 · 옛 마법)
- **소리**: 부드럽고 흐른다. 초성은 ㅎ ㄹ ㄴ ㅁ ㅅ ㅇ 중심, 받침은 ㄴ ㄹ ㅁ만. 된소리 · 거센소리(ㄲ ㄸ ㅋ ㅌ ㅍ ㅊ) 없음. 2~3음절.
- **짜임**: 꾸밈말 + 중심말. `올(첫) + 벤(나무) = 올벤`.

| 어근 | 뜻 | 쓰임 |
|---|---|---|
| 하르 | 심장 | **하르벤**(심장나무), **올하르** 사원(첫 심장) |
| 벤 | 나무 | 하르벤, **올벤** 숲(첫 나무의 숲) |
| 올 | 첫, 옛 | 올벤, 올하르 |
| 이레 | 노래 | **이레린**(노래하는 샘) — 이레린 숲 · 이레린 샘 |
| 린 | 샘 | 이레린, **아스린**(돌샘 — 말라서 사막이 된 옛 샘터) |
| 아스 | 돌 | 아스린 |
| 사 | 새벽 | **사엔**(새벽의 씨앗) |
| 엔 | 씨앗 | 사엔 |
| 누 | 밤 | (예비) |

### 3.2 변경말 — 데니차 사람들 (마을 · 인명 · 가까운 땅 · 화폐)
- **소리**: 소박하고 단단하다(남슬라브 말씨를 본떴다). 2~3음절. 여자 이름은 -아, 남자 이름은 -안 · -오 · -코 · -야로 끝나는 일이 많다. ㅈ ㅊ ㅂ ㄷ 초성이 자주 나온다.
- **인명**: 이름 하나만 쓰고 성은 쓰지 않는다. 화면에는 `직함 + 이름`(대장장이 도브란).

| 낱말 | 뜻 | 쓰임 |
|---|---|---|
| 데니차 | 샛별 | 마을 **데니차**, 데니차 들녘 |
| 벨 · 고라 | 흰 · 산 | **벨고라** 설원 |
| 크라스나 | 붉은 | **크라스나** 협곡(붉은 바위) |
| 모크라 | 젖은 | **모크라** 늪지 |
| 야스나 | 맑은 | **야스나** 초원 |
| 베레그 | 기슭 | **베레그** 해안 |
| 바트라 | 불 | **바트라** 화산 |
| 즈마이 | 용 | 바트라의 늙은 용을 부르는 이름 |
| 모로즈 | 혹한 | 벨고라 설원의 거인 |
| 그로시 | 동전 | 화폐(남부의 두툼한 은화 '그로소'를 변경에서 부르던 말) |
| 오를리차 | 어린 독수리 | 베레그 해안의 난파선 이름 |
| 비스트라 | 빠른 | 데니차를 가로지르는 **비스트라** 개울(Phase 4-B) |

인명 목록: 라다, 도브란, 고란, 밀레나, 베스나, 보얀, 미샤, 안카, 마르파, 다닐로, 야로, 브란코, 페타르, 드라고, 일리야,
즈데노, 체도, 네다, 스탄코, 밀로, 두샨, 즐라타, 벨코, 스네자, 보그단, 페로(Phase 4-B). 남부 출신: 마테오, 로렌초.
새 인물은 이 소리 규칙을 따르고, **이미 있는 이름과 첫 두 글자가 겹치지 않게** 한다(라다/라도 같은 혼동 금지).

### 3.3 남부어 — 몬테라 왕국과 종의 교회 (교회 · 기사단 · 옛 행정)
- **소리**: 격식 있고 둥글다(라틴 · 이탈리아 말씨). 모음으로 끝나는 3음절이 많다. 이중 받침 없음.
- 교회 · 기사단의 **개념어는 한자어로 번역해 쓴다**: 서약, 파약, 축성, 단죄, 예배당, 기사단.

| 낱말 | 뜻 | 쓰임 |
|---|---|---|
| 캄파나 | 종 | **캄파나** 폐허, 캄파나 대성당, 캄파나 종탑 |
| 몬테라 | 산의 땅 | 남쪽 왕국 |
| 세베린 | 엄한 자(이름) | 서약 기사단의 마지막 기사단장 |
| 마테오 | (이름) | 데니차에 남은 교회 필경사, 옛길 길잡이 |

### 3.4 칼둔말 — 균열 아래와 그락족 (균열 · 황무지 · 부족 · 칼둔의 괴물)
- **소리**: 거칠고 닫혀 있다. 받침 ㄱ ㄹ ㅁ ㄴ ㄷ로 끝나는 음절, ㄱ ㄷ ㅋ 초성, 모음 ㅏ ㅜ ㅗ. 2~3음절.
- **그락족 말**은 칼둔말에서 갈라져 나온 사투리다. 그락족은 그라목을 두려워하며 섬긴다.

| 낱말 | 뜻 | 쓰임 |
|---|---|---|
| 칼 · 둔 | 깊은 · 아가리 | **칼둔** 균열 |
| 그라 · 목 | 삼키다 · 주인 | **그라목**(삼키는 주인) |
| 가르 | 그을린 | **가르** 황무지 |
| 우르 · 간 | 큰 · 목소리(우두머리) | **우르간**(그락 대족장) |
| 그락 | 삼키는 무리 | **그락족**의 자칭 — 그락 약탈꾼 · 창잡이 · 전사, 그락 요새 |

### 3.5 공용어 — 한국어 번역층 (짐승 · 물건 · 기술 · 직함)
- 고유명이 아닌 것은 **자연스러운 한국어**로 쓴다. 생활 · 자연 어휘는 고유어(들개, 잉걸, 두루마리, 둔덕, 그믐), 교회 · 기사단 · 제도 어휘는 한자어(서약, 각인, 축성, 단죄).
- **영어 음차는 쓰지 않는다**: 젤리, 골렘, 드레이크, 슬레이어, 포션, 스크롤, 텔레포트, 룬 → 수액덩이, 석인, 비룡, 새벽지기, 물약, 두루마리, 옛길 이동, 각인.

## 4. 작명 규칙 (범주별)

| 범주 | 규칙 | 예 |
|---|---|---|
| 지역 | 고유명 + 지형 일반명사. 고유명의 언어 = 그 땅을 처음 부른 사람들 | 벨고라 설원, 올벤 숲, 캄파나 폐허, 칼둔 균열 |
| 마을 | 변경말 한 단어 | 데니차 |
| 장소(탐험) | 고유명 + 건물 · 지형 | 캄파나 종탑, 올하르 사원, 이레린 샘 |
| NPC | 직함 + 이름(출신 언어). 동물은 마을 사람이 부르는 한국어 이름 | 대장장이 도브란, 길잡이 마테오, 누렁이 |
| 일반 몬스터 | `수식어+종` 붙여 쓰기(한글 5자 이하) 또는 `세력 역할` | 회색늑대, 모래전갈, 그락 창잡이, 칼둔 사냥개 |
| 몬스터 종류말 | 점액 → **-덩이** / 돌 생명체 → **석인** / 죽은 자 → **망령 · 망자 · 백골** / 용 → **비룡** | 수액덩이, 고대 석인, 떠도는 망령, 어린 비룡 |
| 보스 | 고유명(그를 부르는 쪽의 언어) + 별칭 한 구절 | 모로즈 — 벨고라의 혹한 |
| 직업 | 정체성 어휘 + -기사 · -술사 · -사냥꾼 | 서약기사, 각인술사, 밤사냥꾼 |
| 기술 | 동작이 보이는 2~4자. 직업 정체성 어휘는 한 기술에 하나까지 | 방패 강타, 서리 각인, 옛길 도약, 그믐 베기 |
| 연계 | 결과를 말하는 2~4자 | 무너뜨리기, 단죄, 증발 폭발, 급소 |
| 아이템 | 재질 · 출신 + 물건. **고유명은 전설 등급 이상만** | 흑철 단검, 기사단 투구 / 새벽지기, 하르벤 가지 |
| 세트 | 출신 세력 · 장소 | 서약의 갑주, 이레린의 노래, 은늑대 |
| 퀘스트 | 짧은 명사구 · 인물의 말투 | 촌장의 근심, 세 번의 종소리 |
| 장(章) | 사건을 담은 짧은 명사구 | 늦어지는 새벽, 깨어진 서약 |

### 쓰지 않는 말
- **클리셰 수식어**: 에테르, 아르카디아, 루미나, 아르카나, 다크, 블러드, 오브, 엘리시움, 섀도우, 카오스, 소울, 인페르노, 크리스탈, 루나, 솔라, 네크로, 드래곤, 데스, 헬.
- **다른 게임의 고유명**: 아데나, 데스나이트, 바포메트, 집행검, 오리하루콘, 드래곤 슬레이어, 라우풀, 카오틱, 텔레포터.
- **아무 데나 붙는 말**은 지역 · 아이템 이름에 쓰지 않는다: 빛, 어둠, 그림자, 영원, 심연, 파멸, 전설의 (대사 안에서는 괜찮다).

### 이름 점검 (넣기 전에 반드시)
1. 소리 내어 읽어 본다. 다른 한국어 낱말로 들리면 바꾼다(예: '호박 영약'은 호박(채소)으로 들려서 '수액 영약'으로 바꿨다).
2. 같은 화면에 함께 나올 이름과 첫 두 글자가 겹치지 않는지 본다.
3. 몬스터 이름은 **19바이트(한글 6자) 이하** — 서버 패킷(`SUBJECT_ADD_NFY.name[20]`) 제한. 보스 별칭은 클라이언트 표에만 둔다.
4. 용어집에 등록한다. 등록되지 않은 고유명은 데이터에 넣지 않는다.

## 8. 새 콘텐츠 체크리스트
1. 누가 처음 불렀나? → 그 언어의 소리 규칙으로 이름을 짓는다(3장).
2. 범주 규칙(4장)과 쓰지 않는 말 목록을 확인한다.
3. 소리 내어 읽고, 같은 화면 이름과 겹치지 않는지 본다.
4. 용어집(7장)에 먼저 등록하고 데이터에 넣는다.
5. 대사는 5장의 말투 표를 따른다. 화면 요소는 DESIGN_SYSTEM.md의 토큰만 쓴다.
