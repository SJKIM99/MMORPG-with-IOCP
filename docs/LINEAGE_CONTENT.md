# 서버 컨텐츠 확장 — `newclient` 브랜치

`dev` 브랜치의 IOCP 서버 위에 리니지식 규칙(지역 난이도 · 필드 보스 · 강화 · 성향/PK)을 참고한 컨텐츠 네 묶음과,
새 2D 클라이언트 「하르벤」(`Client2D/`)용 확장 프로토콜을 올렸습니다. 클라이언트 빌드/조작은 [`Client2D/README.md`](../Client2D/README.md),
게임 안의 이름 · 용어는 [`WORLD.md`](WORLD.md)를 보세요(코드 식별자 `Adena` · `ADENA_INF` · `Players.adena`는 호환을 위해 그대로 두고, 화면에는 **그로시**로 나옵니다).

## 지킨 원칙

1. **기존 패킷은 한 바이트도 바꾸지 않는다.** `PacketType`·`SystemMessageCode` 등 모든 열거형은 **끝에만** 추가했습니다.
2. **확장 세션 분리.** 새 클라이언트는 `USER_LOGIN_EX_REQ`로 접속하고, 확장 패킷은 그 세션에만 보냅니다.
   `STRESS_TEST` 봇·기존 클라이언트는 `USER_LOGIN_REQ`를 쓰므로 받는 패킷 구성과 부활 규칙(같은 Zone 무작위 위치)이 예전과 같습니다
   → 부하 테스트 조건이 보존됩니다.
3. **서버는 사실만, 연출은 클라이언트.** `EFFECT_NFY`는 “어디서 누가 무엇을”만 알리고 파티클/사운드/흔들림은 클라이언트가 정합니다.
4. **데이터는 공유 헤더 하나.** `Data/WorldData.h`(지역·마을·NPC·상점·충돌), `Data/MonsterTable.h`, `Data/LevelTable.h`(레벨·전투·강화·성향 규칙),
   `Item/ItemTableData.h`를 서버와 클라이언트가 같이 include합니다. 레이아웃·스폰 좌표가 어긋나면 `static_assert`로 **빌드가 실패**합니다.
5. **멱등성.** 상점/옛길 이동(텔레포트) 요청은 `seq`를 실어 보내고, 서버가 플레이어별 마지막 번호를 기억해 재전송을 무시합니다.

## 1. 몬스터 종족 · 지역 난이도 · 보스

- 서버 Zone(500×500칸, 4×4)을 그대로 **16개 지역**으로 삼았습니다. 지역마다 바이옴·난이도(◆1~5)·스폰 가중치·옛길 도착점/요금이 있습니다.

  | | | | |
  |---|---|---|---|
  | 0 벨고라 설원 ◆3 | 1 올벤 숲 ◆2 | 2 크라스나 협곡 ◆4 | 3 바트라 화산 ◆5 |
  | 4 이레린 숲 ◆2 | **5 데니차 들녘 ◆1 (마을 데니차)** | 6 캄파나 폐허 ◆3 | 7 그락 요새 ◆3 |
  | 8 모크라 늪지 ◆3 | 9 야스나 초원 ◆1 | 10 아스린 사막 ◆2 | 11 가르 황무지 ◆4 |
  | 12 서약의 언덕 ◆4 | 13 베레그 해안 ◆2 | 14 굴개미 둔덕 ◆3 | 15 칼둔 균열 ◆5 |

- **일반 몬스터 28종**(수액덩이·그락 약탈꾼·회색늑대·그락 전사·백골 수비병·얼음 석인·비룡·칼둔 전사 …), 선공/비선공, 레벨·HP·공격력·경험치·그로시 범위를 표로 관리.
- **필드 보스 6종**: 벨고라의 혹한 모로즈, 그락 대족장 우르간, 몰락한 기사단장 세베린, 둔덕의 어미 굴개미 여왕, 바트라의 늙은 용 즈마이, 삼키는 주인 그라목. 고정 위치에 5분 주기로 재등장하고,
  주기적으로 **내려찍기**(`BossSlamCast` 경고 → 잠시 뒤 `BossSlamImpact` 범위 피해)를 씁니다. 출현/처치는 `WORLD_NOTICE_INF`로 전 서버 공지.
- 레벨 50까지 경험치 표, 레벨별 최대 HP·기본 공격력·자연 회복량(마을 2배). 데미지 ±15% 편차, 치명타 8%(×1.6).

## 2. 그로시 · 상점 · 각인 강화

- **그로시**(변경의 동전)는 인벤토리 슬롯이 아니라 플레이어 지갑 값입니다(`Players.adena`). 몬스터가 떨어뜨리고, 줍기/구매/판매/옛길 이동 때 `ADENA_INF`로 갱신.
- **상점**: 잡화상 라다(약초 물약·진한 약초 물약·수액 영약·귀환/옛길 두루마리·바람걸음 물약·각인 두루마리),
  대장장이 도브란(직업별 초보자 무기·철검·도브란의 단검·참나무 지팡이·흑철 단검·기본 방어구). 매입은 두 상인 모두.
  NPC 근처(체비셰프 3칸)인지 서버가 검증합니다.
- **옛길 이동**(길잡이 마테오): 지역별 요금(100~3,000 그로시)으로 각 지역 도착점으로 이동.
- **각인 강화**: +6까지 100%, 이후 40→30→22→15→10→8→7→6→5%. 실패하면 무기가 **사라집니다**. 축성된 각인 두루마리는 안전 구간에서 +1~3.
  +6까지 공격력 +1씩, 그 위로 +2씩. **+9 이상 성공은 월드 공지.** 판정·소모·DB 저장은 한 트랜잭션입니다.
- 초보자 지원: 새 캐릭터에게 직업 무기(장착 — 연습용 목검 / 견습생의 지팡이 / 사냥용 단검)·누빔 갑옷·가죽 장화(확장 세션)·약초 물약 20·귀환 3·옛길 2·바람걸음 2·각인 두루마리 1·1,000 그로시.

## 3. 마을 · 귀환 · 사망 패널티

- **데니차**(지역 5 중앙 44×44칸): 성벽·성문·건물·분수·NPC 20명(서버가 배회시킨다). 마을 전체가 **안전지대**(PvP 불가, 몬스터 진입/피해 불가, 회복 2배).
- **귀환 두루마리**: 마을 부활 지점으로. **옛길 두루마리**: 현재 지역 안 무작위 칸(마을·막힌 칸 제외).
- **바람걸음 물약**: 5분 가속(이동 쿨타임 500 → 330ms).
- **사망**: 몬스터에게 죽으면 현재 레벨 필요 경험치의 5% 손실(레벨 다운 없음, PvP 사망은 손실 없음). 확장 세션은 “마을에서 다시 시작”(`USER_RESTART_REQ`)
  또는 30초 뒤 자동으로 마을에서 부활합니다.

## 4. PK · 성향

- 몬스터를 잡으면 성향이 오릅니다(몬스터 레벨/2, 최소 1). **500 이상 = 명예(파란 이름).**
- 다른 플레이어를 먼저 때리면 **60초 동안 적대**(정당방위 대상). 적대·악명 상대를 쓰러뜨리는 것은 벌칙이 없습니다.
- PvP 피해는 평타의 70%(한두 대에 끝나지 않도록).
- 무고한 플레이어를 쓰러뜨리면 **성향 −1000, PK 횟수 +1 → 악명(붉은 이름)**, 전 서버 공지.
- **악명 상태로 쓰러지면 40% 확률로 소지 아이템 하나를 떨어뜨립니다**(강화 수치 유지).
- 안전지대 안에서는 공격 자체가 거부됩니다(`SafeZoneNoCombat`).

## 확장 프로토콜

| 방향 | 패킷 | 내용 |
|---|---|---|
| C→S | `USER_LOGIN_EX_REQ` | 확장 로그인(버전 포함) |
| C→S | `USER_RESTART_REQ` | 사망 시 마을에서 다시 시작 |
| C→S | `USER_TARGET_ATTACK_REQ` | 대상 지정 근접 공격(몬스터/플레이어 공통, PK 포함) |
| C→S | `ITEM_ENCHANT_REQ` | 각인 두루마리 사용(두루마리 슬롯, 무기 슬롯) |
| C→S | `SHOP_BUY_REQ` / `SHOP_SELL_REQ` / `NPC_TELEPORT_REQ` | 상점·옛길 이동(`seq`로 멱등) |
| S→C | `USER_INFO_EX_INF` | 내 레벨·경험치·다음 레벨 경험치·그로시·성향·PK·공격력·상태 플래그 |
| S→C | `SUBJECT_INFO_EX_NFY` | 주변 플레이어의 레벨·성향·적대/가속/안전지대·무기 강화 수치 |
| S→C | `ITEM_LIST_EX_ACK` / `ITEM_SLOT_EX_INF` | 강화 수치를 포함한 인벤토리 스냅샷 / 슬롯 하나 갱신(모든 슬롯 변경 경로에서) |
| S→C | `ADENA_INF` | 그로시 변경(사유 포함) |
| S→C | `ENCHANT_RESULT_ACK` / `SHOP_RESULT_ACK` | 강화 결과 / 구매·판매·옛길 이동 결과 |
| S→C | `SUBJECT_DAMAGE_NFY` | 누가 누구에게 얼마를(치명타·스킬·사망 플래그) |
| S→C | `EFFECT_NFY` | 이펙트 트리거(기술·레벨업·물약·옛길 이동·강화·보스 내려찍기·PK·부활·보스 출현) |
| S→C | `WORLD_NOTICE_INF` | 전 서버 공지(보스 출현/처치, 고강화 성공, PK) |
| S→C | `SC_CHAT_EX` | 채널 채팅(일반/전체/시스템, 보낸 사람 이름 포함) |

확장 패킷도 `STRESS_TEST`의 수신 버퍼(255바이트)를 넘지 않도록 `static_assert`로 크기를 묶었습니다.

## 그 밖의 변경

- `STRESS_TEST/NetworkModule.cpp`: “아이템 id 2번부터 전부 장비” 가정이 새 아이템(그로시·두루마리 등)으로 깨져서,
  장비 id 목록(2~6, 15~18)으로 판정하도록 수정. 봇이 주운 두루마리를 무기로 착각해 부하 패턴이 바뀌는 것을 막습니다.
- `Data/MonsterTable.h`: 보스 크기(최대 260%)가 `uint8_t`를 넘쳐 `scale`을 `uint16_t`로(MSVC에서는 축소 변환 오류).
- **Phase 1(조작 · 이동, `docs/upgrade/PHASE_1.md`) — 새 패킷 0개, DB 변경 없음.**
  - `Data/MoveRule.h` `kCatchupMs` 200 → **500**: 확장 세션 이동 검증(`USER_MOVE_EX_REQ` → `UserHelper::HandleMoveEx`)의 토큰 버킷이
    늦게 온 패킷의 잃은 시간을 되찾는 창. TCP 재전송 한 번(200~450ms) 뒤 한꺼번에 도착한 대각 걸음(395ms)이 TooFast로 거절돼
    1~1.4칸 되돌림이 생기던 것을 막는다(모의 시험 `--netsim 150/40/2` 6분: 거절 11 → 0). 오래 쉬었다가 한꺼번에 보낼 수 있는 양이
    350 → 650ms어치(직선 두세 걸음)로 늘 뿐 평균 속도 상한은 그대로다. 레거시 `USER_MOVE_REQ`(STRESS_TEST 봇)는 `Route.cpp`의 쿨타임을 따로 써서 영향이 없다.
  - `Data/CombatData.h`: 돌진 · 옛길 도약 · 잔상 회피 설명을 "커서 쪽으로"로(표시 문구만 — 판정 · 패킷 그대로).
